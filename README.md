## Introduction
My project is an Expense Tracker.This program keep record of daily expenses and calculate how much money has been spent. I made this project for
my CS50P final project to practise the Python concepts I learned during the course. It is a
simple program that runs in the terminal and uses a menu to let the user choose what they want
to do.
## Features
The program has four main options. The first option allows the user to add a new expense by
entering its date, category, amount, and a short note. For example, a user can enter Food as the
category and Lunch as the note. The program checks that the date and category are not empty
and that the amount is a valid positive number.
The second option displays all the expenses that have been added. The third option calculates
and displays the total spending. The last option saves the expenses and exits the program. If
the user enters an amount that is not a number or enters zero or a negative amount, the
program shows an error message instead of accepting it.
Files in the Project
project.py
This is the main file of my project. It contains the functions. The
"add_expense" function checks the entered information and adds the expense to a list. The
"calculate_total" function adds all the expense amounts and returns the total. The
"show_expenses" function displays the expenses in a readable format.
The "load_expenses" function reads previously saved expenses from a CSV file, while the
"save_expenses" function writes the current expenses to that file. The "main" function displays
the menu and controls the program. I also used "if __name__ == "__main__":" to run the main
function when the file is executed directly.
test_project.py
This file contains tests written with pytest. I made tests to check whether expenses are added
correctly, invalid amounts are rejected, and the total is calculated correctly. I also tested saving
and loading expenses to check that the information is stored and read back properly.
expenses.csv
This file stores the expenses so that they can be loaded again when the program runs later. The
program creates or updates this file when the user chooses to save and exit. It is generated by
the program, so it does not need to be created manually before the first run.
## Design Choices
I decided to use a list of dictionaries to store the expenses . Each
dictionary contains the date, category, amount, and note of one expense.The reason i choose this is it keeps related information together and makes it easier to display and calculate
expenses.
I used a CSV file to store data in rows and columns. I used Python's
"csv" library to read and write the file and "pathlib" to define its location. I made various function to handle operations.
Another thing was to use "try" and "except" to handle invalid amounts and file errors. This
helps the program show understandable error messages instead of stopping unexpectedly in
common error situations.
How to Run the Project
Keep "project.py" and "test_project.py" in the same
project folder. Open a terminal in that folder and run:
python project.py
To run the tests, use:
pytest test_project.py
